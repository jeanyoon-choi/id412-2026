## 1. API 소개 [#1-api-introduction]

- <Term id="api" />란?
  - 컴퓨터 사이, 혹은 프로그램 사이의 연결. 다른 소프트웨어에 서비스를 제공하는 소프트웨어 인터페이스의 한 종류. - Wikipedia
- 여러 종류의 API
  - 날씨, 뉴스, 지도, 공공 데이터
  - OpenAI API, Anthropic API (Claude)
  - Replicate API
  - Microsoft Azure/AWS/Google Cloud
- Next.js와의 통합
  - App Router: <Term id="routeHandler">Route Handler</Term> [LINK](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)
    - Route Handler란: 별도 백엔드 서버 없이 Next.js 안에 서버 로직을 바로 만드는 것
    - `app/api/<name>/route.ts` → 페이지에서 `fetch("/api/<name>")`
    - 서버에서 돈다. API 키가 브라우저에 절대 안 간다
    - Route Handler는 Vercel에 배포된다 (소켓 relay와 달리)

**무료 API**

| API | 데이터 | 키 |
| --- | --- | --- |

| [공공데이터포털](https://www.data.go.kr/) | 한국 공공 데이터 | 무료 키 |

**키 없이**: 페이지에서 `fetch`로 바로 호출

```tsx
const response = await fetch(
  "https://api.open-meteo.com/v1/forecast?latitude=36.37&longitude=127.36&current=temperature_2m,wind_speed_10m",
);
const data = await response.json();
console.log(data.current.temperature_2m, data.current.wind_speed_10m);
```

**키가 있을 때**: Route Handler에서 호출

- 1단계. 가입하고 API 키 만들기
  - New York Times: https://developer.nytimes.com/
- 2단계. API 키를 <Term id="env">`.env.local`</Term>에 저장: `NYT_API_KEY=...`
  - `.env.local`이란? 서버에서만 읽는 환경변수
  - `NEXT_PUBLIC_` 접두사를 붙이지 마라. 그 접두사가 붙으면 브라우저로 나간다. 즉 공개된다
- 3단계. `.gitignore` 확인: `.env*`는 이미 들어 있다. 키는 절대 커밋하면 안 된다
- 4단계. Route Handler에 API 코드 작성: `app/api/<name>/route.ts`. 키는 `process.env.NYT_API_KEY`로 읽는다
- 5단계. 프론트엔드에서 fetch로 이 Route Handler 호출

## 3. 사운드: Tone.js [#3-sound-tonejs]

- <Term id="webAudio" />: 브라우저의 오디오 엔진. 오실레이터, 샘플, 이펙트, 분석(볼륨, FFT)
- <Term id="tonejs" />: Web Audio 위의 Javascript 라이브러리. 음악가 친화적 (Synth, Transport, Effect) [LINK](https://tonejs.github.io/)
- 템플릿에 이미 설치됨: `tone`
- 규칙
  - 오디오는 사용자 제스처(탭/클릭) 뒤에만 시작된다: 이벤트 핸들러 안에서 `await Tone.start()`
  - 마이크 입력은 HTTPS 필요 (W2 A3 참고)

```tsx
import * as Tone from "tone";

async function play() {
  await Tone.start();
  const synth = new Tone.Synth().toDestination();
  synth.triggerAttackRelease("C4", "8n");
}
```

**사운드를 만드는 방법**

1. 합성: `Tone.Synth`, `Tone.FatOscillator`, `Tone.NoiseSynth`. 파라미터 → 주파수, 볼륨
2. 샘플: `public/`의 녹음 파일을 `Tone.Player` / `Tone.Sampler`로 재생
3. 시퀀싱: `Tone.Transport`, `Tone.Loop`. 템포가 파라미터
4. 이펙트: 소스와 스피커 사이에 `Tone.Filter`, `Tone.Reverb`, `Tone.Distortion`, `Tone.FeedbackDelay`
5. 마이크를 입력으로: `Tone.UserMedia` + `Tone.Meter` / `Tone.FFT`
6. 음성: 브라우저의 `speechSynthesis`, 또는 Route Handler를 거친 TTS API

**사운드 예제**

1. Tone Pad: 포인터 → 음높이, 필터: [sound/tone-pad](/experiments/w3/sound/tone-pad)
2. 데이터 → 사운드 (드론, 바람, 심장박동, 충격음): [w1/snp](/experiments/w1/snp) → `sound.ts`
3. 마이크 → 파라미터: [w1/video](/experiments/w1/video)

- 방법: 콘텐츠를 프레임 안에 넣는다. 프레임을 옮기고 크기를 바꿔서 (top, left, width, height) 벽에 맞춘다. 프레임 밖은 전부 검정
  - 예제: projection-mapping ([left](/experiments/w3/projection-mapping?side=left) · [right](/experiments/w3/projection-mapping?side=right)) → `app/experiments/w3/projection-mapping/`
  - `MappingFrame.tsx`: 프레임. `Content.tsx`: 프레임이 감싸는 너의 콘텐츠
  - 콘텐츠의 크기는 창(`100vw` / `100vh`)이 아니라 프레임(`100%`)에서 받는다
- 참고: https://github.com/jeanyoon-choi/xdlab-mapping
