## 3. Why Creative Web Dev?

**TouchDesigner vs. Web Dev**

- TouchDesigner
  - Strong in Audio-Visual Creation
  - Limitation of Node-based Logic
  - More 'Visual' Centric, Sensor-based Interaction Centric
- Web Development
  - (Used to have) a very stiff learning curve
  - But now with LLMs, your imagination is your only limit
  - More systemic approach - Narrative-oriented
  - More 'Context/Narrative' Centric, Semantic Interaction Centric
  - You can combine TD Output + Web Input (Which we will not cover though)

**Creative Coding vs. Web Dev**

- Traditional Approach of Art/Design Institution teaching Coding: p5.js / Processing
  - More of Creative Coding rather than Creative Software
  - Easy to learn but limited community / far from industry standard
- Creative Web Dev
  - Hard to learn
  - But easily compatible & integratable with all the Web Industry Standards
  - Dive Deeper into the field of software & frontend engineering
  - More System/Platform/Functionality-Oriented than Creative Coding

|                | Creative Coding        | Web Dev                                            | Creative Web Dev                                    |
| -------------- | ---------------------- | -------------------------------------------------- | --------------------------------------------------- |
| Major Usage    | Art School Context     | Industry Standard                                  | Starts from an Art School, Headed towards the Industry |
| Focus          | Visual-Oriented        | Functionality-Oriented                             | Functionality-Oriented                              |
| Expandability  | Limited                | Expandable                                         | Expandable                                          |
| Characteristic | Experimental by Nature | Practical by Nature                                | Experimental by Nature                              |
| Community      | Small Community        | Gigantic Community                                 | Growing                                             |
| Learning Curve | Relatively Easy        | Very Hard yet Rewarding (There is no free lunch)   | Hard yet rewarding (Now it's kinda easy w/ LLMs)    |

- DO USE LLMs and coding agents within the Class

- Your learning curve… Accelerated much faster

**Speculating the future of Coding within the Post-LLM**

- Language-based tools with Strong & Large Community will Dominate
  - React/Next based Frontend Coding
  - Visual-based/Node-based programming might lose attraction
- Lots of traditional Web Developers (might) lose their jobs
- BUT Professionals with Domain Knowledge can now integrate Programming very flexibly: It's an opportunity for you, as designers, to leverage this chance as much as you can
- In a near future, programming will become more and more easier
  - This lecture is already easier than what it should be a year ago, and will be easier next year
- Please update yourself on the latest trends and do not hesitate to integrate coding/programming extensively within your design practice/research
