## 3. 왜 크리에이티브 웹 개발인가? [#3-why-creative-web-dev]

**소프트웨어 엔지니어링의 현재**

- 모델 성능은 선형으로 늘지 않는다. 두 배씩 는다.
  - METR은 모델이 혼자서 끝낼 수 있는 소프트웨어 작업의 길이(인간 전문가 기준 시간)를 측정한다
  - 2023년: 몇 분. 2025년: 몇 시간. 2026년: 하루치 작업, 그리고 벤치마크가 더 이상 못 따라간다
  - 두 배가 되는 데 걸리는 시간: 약 7개월 (2019–2024), 2023년 이후로는 약 4개월

- 이게 소프트웨어 엔지니어링에 뜻하는 것
  - 코드를 쓰는 게 더 이상 병목이 아니다. 뭘 원하는지 아는 게 병목이다

  - '소프트웨어' 자체의 가치가 무너지고 있다. 누구나 소프트웨어를 만들 수 있다. 모두가 만들 것이다

- 2020년대: 같은 일이 소프트웨어에 일어나고 있다
  - AI가 소프트웨어를 무한히 복제 가능하게 만들었다. '만드는' 기술이 더 이상 관문이 아니다
  - 이건 소프트웨어 엔지니어링뿐 아니라, 소프트웨어를 쓰는 예술적 표현도 해방시킨다. '먼저 만들 줄 알아야 한다'는 제약이 사라졌다
  - 소프트웨어 만들기가 이제 그림 그리기보다 쉽다. 아마 훨씬 쉽다
  - 역설적으로, 그래서 소프트웨어를 이용한 예술적 실험이 폭발할 것이다. 싼 매체 → 거친 실험. 사진 → 현대미술과 똑같이
- 굉장히 중요하고, 굉장히 흥미로운 시대
  - 우리는 같은 규모의 또 다른 혁명을 목도하고 있다. 엄청난 가능성, 그리고 동시에 기존의 많은 관행이 사라질 것이다
  - '소프트웨어가 어떻게 만들어지는가'에 대해 아는 것 대부분이 1년 안에 낡는다. 이 강의의 일부도 포함해서
  - 이 워크숍에서 할 일: 프로그래머가 되는 게 아니라, 이 순간을 쓰는 것. 뭘 만들지 정하고. 만들고. 반복해라

**단서: AI는 통계적 기계다**

- AI는 평균으로 회귀한다. 언제나
  - 모델은 통계적 기계다. 가장 그럴듯한 다음 것을 예측한다
  - [확률적 앵무새 (Stochastic Parrot)](https://en.wikipedia.org/wiki/Stochastic_parrot) (Bender 외, 2021): 학습 데이터의 패턴을, 그럴듯하게, 의미 없이 반복한다
  - 창작 과정을 통째로 맡기면 결과는 평균으로 수렴한다. '어디서 본 것 같은데', 전혀 새롭지 않은

  - AI가 좋은 소프트웨어를 만들어준다고 네가 창작자가 되는 건 아니다. 무한 소프트웨어의 시대에는 더욱

## 5. AI 에이전트 사용법 [#5-how-to-use-ai-agents]

- 최상위 모델은 몇 달마다 바뀐다. 현재 라인업은 [OpenAI 모델](https://developers.openai.com/api/docs/models)과 [Claude 모델](https://platform.claude.com/docs/en/about-claude/models/overview)에서 확인
- 이 워크숍에서 이 API를 직접 부르는 일은 (W3 전까지는) 없다. 코딩 에이전트를 통해 쓴다

**코딩 에이전트**

- 코딩 에이전트 = 모델 + 도구. 네 파일을 읽고, 고치고, 명령을 실행하고, 에러를 읽고, 다시 시도한다. 네가 설명하면 만들고, 네가 검토한다
- [Codex](https://chatgpt.com/codex) (OpenAI): CLI, VS Code 확장, 클라우드. ChatGPT 요금제에 포함. GPT-6 Astra / GPT-6.1 Sol 사용
- <Term id="claudeCode" /> (Anthropic): 터미널, VS Code 확장, 데스크톱 앱, 웹. Claude 구독 필요. Claude Opus 5.5 / Fable 5.1 사용
- [Cursor AI](https://cursor.com/), [GitHub Copilot](https://github.com/features/copilot), [Gemini CLI](https://github.com/google-gemini/gemini-cli): AI 통합 에디터와 다른 CLI들. 같은 아이디어, 다른 회사
- **우리는 VS Code + Claude Code**를 쓴다. 모델은 Claude Opus 5.5

**기본 셋업: VS Code + Claude Code**

1. <Term id="vscode" /> 설치: https://code.visualstudio.com/Download
2. Claude Code (CLI) 설치. 터미널을 열고 실행
   - macOS: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
   - 새 터미널을 열고 `claude --version` 입력. 버전 번호가 나오면 성공
3. VS Code에 Claude Code 확장 설치
   - 확장 탭 열기: `Cmd+Shift+X` (Mac) / `Ctrl+Shift+X` (Windows)
   - "Claude Code" 검색 (제작: Anthropic) → Install
   - 커맨드 팔레트 (`Cmd+Shift+P` / `Ctrl+Shift+P`)에서 "Claude Code" 입력 → **Open in New Tab**
4. VS Code에서 프로젝트 폴더를 열고, 터미널을 열고 (`` Ctrl+` ``), `claude` 입력
5. 수업용 계정으로 로그인 (아래)
6. `/model` 입력 후 **Claude Opus 5.5** 선택

**수업용 계정 (공용)**

- 워크숍에서 재학생용 Claude Max ($200/월) 계정을 **10/19부터 12/19까지** 무료로 제공한다
- 로그인이 필요한 사람은 **10/21 수업 아침 9시 50분까지** 오면 직접 준다
- <span className="danger">규칙. 하나라도 어기면 계정 사용 권한을 회수한다</span>
  1. ID412 수업 용도로만 쓴다
  2. 수업 외부의 계정이나 프로젝트에 쓰지 않는다
  3. **Claude Fable 5.1 사용 금지. Claude Opus 5.5만 쓴다** (모델이 바뀌면 달라질 수 있음)
  4. 사용량이 하나로 묶여 있다. 양심적으로, 필요한 만큼만, 아껴서 써라. 다 쓰면 모두가 못 쓴다
  5. 로그인 정보를 수업 밖 사람과 공유하지 않는다. 계정 설정이나 비밀번호를 바꾸지 않는다
  6. 프롬프트에 개인정보, 비밀번호, API 키를 넣지 않는다

- 믿기 전에 뭘 바꿨는지 읽어라: `git diff`. 버리려면 `git restore .`, 남기려면 `git commit`
- 한 번에 한 가지. 작은 단계로, 매번 브라우저에서 확인
- 레포의 `AGENTS.md`가 에이전트에게 이 프로젝트의 규칙을 알려준다. 자세한 건 W1에서
