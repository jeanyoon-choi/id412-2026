## 3. Why Creative Web Dev?

**State of Software Engineering**

- Model capability is not growing linearly. It is doubling.
  - METR measures how long a software task (in human-expert time) a model can finish on its own
  - 2023: minutes. 2025: hours. 2026: a full working day, and the benchmark can no longer keep up
  - Doubling time: ~7 months (2019–2024), ~4 months since 2023

<CapabilityChart />

- What this means for Software Engineering
  - Writing code is no longer the bottleneck. Knowing what you want is
  - **Imagination is the biggest bottleneck.** Not syntax, not frameworks, not the tool
  - 'Software' used to be expensive: a team, months, a budget. Now it is a prompt, an afternoon, and a laptop
  - The value of 'software' itself is collapsing. Anyone can make software. Everyone will

- This is the Photography moment
  - Walter Benjamin, [*The Work of Art in the Age of Mechanical Reproduction*](https://en.wikipedia.org/wiki/The_Work_of_Art_in_the_Age_of_Mechanical_Reproduction) (1935)
  - Before photography, making an image required years of training. Painting was a craft, and the craft was the gate
  - Photography made the image infinitely reproducible. The 'aura' of the hand-made image collapsed
  - Art did not die. Painting was freed from the obligation to depict. Impressionism, Abstraction, Dada, Conceptual Art… Modern Art exploded *precisely because* the image became cheap
  - I actually created an artwork about this: [SoTA (State-of-the-Art)](https://www.xdlab.net/projects/sota)

- 2020s: the same thing is happening to software
  - AI made software infinitely reproducible. The craft of 'building' is no longer the gate
  - This frees not only software engineering, but artistic expression that uses software. The constraint 'you must be able to build it first' is gone
  - Making software is now easier than painting. Arguably much easier
  - Paradoxically, this is why artistic experiments with software will explode. Cheap medium → wild experimentation. Just like Photography → Modern Art
- A very important, and very interesting time
  - We are witnessing another revolution of the same scale. Enormous possibility, and at the same time many of the existing practices will vanish
  - Most of what you know about 'how software is made' will be outdated within a year. Including parts of this lecture
  - Your job in this workshop: not to become a programmer, but to use this moment. Decide what you want to make. Make it. Iterate

**Caveat: AI is a Statistical Machine**

- AI regresses to the mean. Always
  - A model is a statistical machine. It predicts the most probable next thing
  - A [Stochastic Parrot](https://en.wikipedia.org/wiki/Stochastic_parrot) (Bender et al., 2021): it repeats patterns from its training data, convincingly, without meaning
  - Hand the whole creative process to it, and the output converges to the average: 'I have seen this somewhere', but nothing new

  - AI generating good software doesn't make you a creator. Not in the age of infinite software
  - Generation is cheap. Direction is not
- This is the real question of this workshop

## 5. How to use AI Agents

**Models (as of Oct 2026, API price per 1M tokens, input / output)**

| Company   | Model            | Position                                              | Price        |
| --------- | ---------------- | ----------------------------------------------------- | ------------ |
| OpenAI    | GPT-6 Astra      | Most capable. Complex reasoning and coding            | $10 / $50    |
| OpenAI    | GPT-6.1 Sol      | Near-Astra for coding and professional work, cheaper  | $2 / $10     |
| OpenAI    | GPT-6 Luna       | Fastest, cheapest. High-volume simple tasks           | $0.10 / $0.50 |
| Anthropic | Claude Fable 5.1 | Most intelligent. Demanding reasoning, long agentic work | $10 / $50 |
| Anthropic | Claude Opus 5.5  | Long-running agentic coding. The recommended default  | $4 / $20     |
| Anthropic | Claude Sonnet 5.5 | Speed + intelligence balance                         | $2 / $10     |
| Anthropic | Claude Haiku 5.5 | Fastest, cheapest                                     | $0.10 / $0.50 |

- Frontier models change every few months. Check [OpenAI models](https://developers.openai.com/api/docs/models) and [Claude models](https://platform.claude.com/docs/en/about-claude/models/overview) for the current lineup
- You don't call these APIs directly in this workshop (until W3). You use them through a coding agent

**Coding Agents**

- A coding agent = a model + tools. It reads your files, edits them, runs commands, reads the errors, and tries again. You describe, it builds, you review
- [Codex](https://chatgpt.com/codex) (OpenAI): CLI, VS Code extension, cloud. Included in ChatGPT plans. Runs GPT-6 Astra / GPT-6.1 Sol
- <Term id="claudeCode" /> (Anthropic): terminal, VS Code extension, desktop app, web. Needs a Claude subscription. Runs Claude Opus 5.5 / Fable 5.1
- [Cursor AI](https://cursor.com/), [GitHub Copilot](https://github.com/features/copilot), [Gemini CLI](https://github.com/google-gemini/gemini-cli): AI-integrated editors and other CLIs. Same idea, different vendors
- **We use VS Code + Claude Code**, with Claude Opus 5.5

**Basic setup: VS Code + Claude Code**

1. Install <Term id="vscode" />: https://code.visualstudio.com/Download
2. Install Claude Code (the CLI). Open a terminal and run
   - macOS: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
   - Open a new terminal, type `claude --version`. A version number means it worked
3. Install the Claude Code extension in VS Code
   - Open the Extensions view: `Cmd+Shift+X` (Mac) / `Ctrl+Shift+X` (Windows)
   - Search "Claude Code" (publisher: Anthropic) → Install
   - Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`), type "Claude Code", select **Open in New Tab**
4. Open your project folder in VS Code, open the terminal (`` Ctrl+` ``), type `claude`
5. Log in with the class account (below)
6. Type `/model` and select **Claude Opus 5.5**

**How to work with an agent**

- Describe what you want, specifically. Say "App Router", say which file, paste the error
- Read what it changed before you trust it: `git diff`. Throw it away with `git restore .`, keep it with `git commit`
- One task at a time. Small steps, each one checked in the browser
- `AGENTS.md` in the repo tells the agent the rules of this project. More in W1
