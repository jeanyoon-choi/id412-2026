## 1. API: Introduction

- What is API?
  - An application programming interface is a connection between computers or between computer programs. It is a type of software interface, offering a service to other pieces of software. - Wikipedia
- Various types of APIs
  - OpenAI API, Anthropic API (Claude)
  - Replicate API
  - Microsoft Azure/AWS/Google Cloud
- Integration with Next.js
  - App Router: Route Handlers [LINK](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)
    - What is a Route Handler: Create Server-side logic directly in your Next.js without having to create a separate Backend Server
    - `app/api/<name>/route.ts` → `fetch("/api/<name>")` from your page
    - Runs on the server. Your API key never reaches the browser
    - Route Handlers DO deploy to Vercel (unlike the socket relay)

## 2. LLM API

- Step 1. Register and create an API Key
  - OpenAI: https://platform.openai.com/api-keys
  - Anthropic: https://platform.claude.com/
  - Bring your own key. Usage is billed to your account
- Step 2. Store your API Key in `.env.local`
  - What is `.env.local`? Environment variables, read only on the server
  - Do NOT prefix it with `NEXT_PUBLIC_`. Anything with that prefix is shipped to the browser, i.e. public
- Step 3. Check `.gitignore`: `.env*` is already there. Your key must never be committed
- Step 4. Add the package: `pnpm add openai` (or `pnpm add @anthropic-ai/sdk`)
- Step 5. Write the API code in a Route Handler: `app/api/<name>/route.ts`
- Step 6. On the frontend, call this Route Handler via fetch
  - How you communicate with the Route Handler
- Read Documentation
  - OpenAI: https://platform.openai.com/docs/overview
  - Anthropic: https://platform.claude.com/docs
- Other Useful Functionalities & External Libraries
  - Tools & Structured Output
  - Realtime / voice APIs
  - Image generation
  - Vercel AI SDK
- LLM is currently a big heap, worth digging deeper

## 3. Sound: Tone.js

- Web Audio API: the browser's audio engine. Oscillators, samples, effects, analysis (volume, FFT)
- Tone.js: Javascript library on top of Web Audio, musician-friendly (Synths, Transport, Effects) [LINK](https://tonejs.github.io/)
- Already installed in the template: `tone`
- Rules
  - Audio starts only after a user gesture (tap/click): `await Tone.start()` inside an event handler
  - Microphone input requires HTTPS (see W2 A3)
- Final term: Sound is mandatory

**Sound examples**

1. Hello Tone: a synth on tap
2. Parameter → sound (mobile → screen)
3. Microphone → parameter
